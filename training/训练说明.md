# CNN + LSTM 训练说明

## 已完成的模型

本项目当前训练的是 **N-BaIoT 三分类轻量化 CNN + LSTM 模型**：

- `0 = Normal`
- `1 = Mirai`
- `2 = Gafgyt`

输入不再是错误的单行 `(1, 21)`，而是连续 16 条记录组成的时序窗口：

```text
(batch_size, 16, 21)
```

原始 CSV 有 115 个统计特征。训练脚本先执行方差过滤、相关性过滤和监督式筛选，最终保留 21 个特征。

## 当前已训练版本

本次 CPU 验证训练使用：

- 训练集：每类 6000 个序列，共 18000 个
- 验证集：每类 1000 个序列，共 3000 个
- 测试集：每类 1500 个序列，共 4500 个
- 设备 8、9 完全不参与训练，用作独立设备测试
- 序列长度：16
- 训练轮数：6

测试集准确率为 **98.22%**。具体指标见：

```text
backend/data/training_report.json
backend/data/classification_report.csv
backend/data/confusion_matrix.csv
```

## 直接使用已训练模型

系统默认优先加载：

```text
backend/data/best_model.ts
```

这是 TorchScript 模型，不依赖 ONNX Runtime 即可由 PyTorch 加载。

## 重新正式训练

先保证项目环境已经初始化，然后双击：

```text
训练CNN_LSTM.bat
```

输入九个 ZIP 文件所在的文件夹路径。脚本会直接读取压缩包，不需要提前解压数 GB 数据。

也可以在项目根目录运行：

```powershell
.\.venv\Scripts\python.exe training\train.py `
  --zip_dir "D:\你的数据文件夹" `
  --epochs 12 `
  --batch_size 512
```

## 检测单个 CSV

```powershell
.\.venv\Scripts\python.exe training\predict_csv.py "D:\data\9.mirai.ack.csv"
```

CSV 必须保留 N-BaIoT 原始 115 列字段。

## 现阶段边界

当前训练模型能可靠处理 N-BaIoT 已提取特征 CSV。项目中的原始 PCAP 实时特征提取仍未实现与 N-BaIoT 的 115 维增量统计完全一致，因此不能把 PCAP 演示结果当作正式模型实验结果。正式答辩应以 CSV 测试、留出设备测试和树莓派推理性能测试为准。

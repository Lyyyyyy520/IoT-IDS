# 智慧社区 IoT 僵尸网络入侵检测系统 —— 项目总结

> 更新日期：2026-10-09。本文总结项目目标、现有固件/执行器、以及剩余工作。
> 详细执行步骤见 [17-field-demo-runbook.md](17-field-demo-runbook.md)。

## 一、项目要实现的内容

**一句话目标**：基于轻量化深度学习（设备图 GNN），对智慧社区内 6 台真实 IoT 设备做
僵尸网络入侵检测，现场演示「设备接入 → 实时监视 → 联动 → 攻击 → 检测判红 → 事件 → 处置」的完整闭环。

**完整闭环（13 步）**：

```
① 6 板上电入网 → ② 发现 → ③ 认领 → ④ 在线 → ⑤ 监视(拓扑/风险色)
→ ⑥ 联动(CoAP) → ⑦ 攻击(被感染设备发洪水) → ⑧ 抓包 → ⑨ GNN 判红
→ ⑩ 事件落库 → ⑪ 处置(block) → ⑫ 结案 → ⑬ (可选)移动端
```

## 三、现有固件

### 3.1 `edge/esp32/community_device/community_device.ino`（5 块 C3 共用，编译时选类型）

- 5 种 `DEVICE_TYPE`：`DEVICE_DOOR` / `DEVICE_LIGHT` / `DEVICE_PLUG` / `DEVICE_SENSOR` / `DEVICE_SPEAKER`
- 编译开关 `LINK_SIM_MODE`：**0 = 旧行为**（30s 无条件裸 `evt` 联动）；**1 = 现场演示**（见下）
- MQTT 心跳：每 5 秒 `community/{device_id}/status`，schema v2，含 MAC/IP/遥测

**LINK_SIM_MODE=1 的核心能力**：

| 能力 | 说明 |
|------|------|
| 事件类联动载荷 | `evt:<事件类>:<角色>`（如 `evt:door_open:door-01`），替换裸 3 字节 `evt` |
| 发送方白名单 | 监听端校验来源 IP，终结"任意 UDP 包万能触发" |
| 角色托管 | 6 块板模拟完整社区联动：speaker 托管门磁→light；sensor 托管烟雾→door/light、温湿度→plug；door 托管门禁→speaker/camera |
| 事件驱动触发 | door 开门按键(可选)、sensor DHT11 高温阈值(>30℃/<28℃ 回差)；`LINK_DEMO_FORCE` 演示兜底 |
| 执行器语义修复 | 插座：高温→通电 / 降温→断电（不再 toggle）；门禁解锁/摄像头录像改 millis 状态机（不阻塞心跳） |
| 攻击洪水对齐 | 约 2/3 打内网受害机 .200:9000 + 1/3 打外网随机端口 UDP（命中规则签名） |
| 运行时开关 | MQTT `linkage_off` / `linkage_on` 切场景免重烧 |

### 3.2 `edge/esp32/camera_device/camera_device.ino`（ESP32-CAM）

- MQTT 心跳 5s + 云台缓慢扫描；
- 联动：收到 `evt:door_open` → 云台转向门禁方向"录像"2 秒（非阻塞）；
- 周期出向流量（60s 一次 UDP 到 8.8.8.8:80，视频上行边的流量证据）；
- 攻击：云台乱转 + UDP 洪水。

### 3.3 联动关系（6 条，`edge/community_devices_physical.py`）

| 发起方 | 目标 | 语义 |
|--------|------|------|
| speaker-01（托管门磁 ds-01~06） | light-01 | 门磁 → 楼道灯 |
| sensor-01（托管烟雾 sm-01~03） | door-01 | 烟雾 → 门禁解锁 |
| sensor-01 | light-01 | 烟雾 → 应急亮灯 |
| sensor-01（温湿度） | plug-01 | 高温/降温 → 插座通断电 |
| door-01（门禁） | speaker-01 | 开门 → 音箱播报 |
| door-01 | camera-01 | 开门 → 摄像头录像 |

## 四、现有执行器（每台设备的接线）

| 设备 | 引脚 | 执行器 | 攻击反应 | 联动反应 |
|------|------|--------|---------|---------|
| door-01 门禁 | **IO0**（GPIO0） | SG90 舵机 | 舵机开锁（0°） | 烟雾→解锁 500ms 回锁 |
| light-01 路灯 | **IO1**（GPIO1） | LED + 220Ω 电阻 | 疯狂闪烁 | 门磁/烟雾→应急闪 3 次 |
| plug-01 插座 | **IO2**（GPIO2）⚠️ | 继电器模块（低电平触发） | 反复通断 | 高温→通电 / 降温→断电 |
| speaker-01 音箱 | **IO4**（GPIO4） | 有源蜂鸣器 | 持续怪声 | 开门→响 200ms |
| sensor-01 传感器 | **IO3**（GPIO3） | DHT11（传感器，无执行器） | 上报假数据 99.9℃ | — |
| camera-01 摄像头 | **IO2**（GPIO2）⚠️ | SG90 云台舵机 | 云台乱转 | 开门→转向录像 |

> ⚠️ **plug 和 camera 的 GPIO2 是启动 strapping 引脚**：接好执行器后必须上电实测，
> 若板子起不来（被执行器拉低），改 GPIO5/6/7/10 并重烧。

|----|------|
| 烧录 Flash Mode 用 QIO → 板子不跑 | 改 **DIO** |

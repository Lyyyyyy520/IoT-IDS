# CNN + LSTM 首次真实数据训练结果

## 模型结构

- 输入：`16 × 21` 时序特征
- CNN：两层深度可分离一维卷积 + SE 通道注意力
- LSTM：单层 64 隐藏单元 + 时序注意力
- 融合：CNN 与 LSTM 特征拼接后完成三分类
- 参数量：36,008，约 0.036M

## 数据划分

- 设备 1—7：训练和验证
- 设备 8、9：完全留出测试
- 训练：18,000 个序列
- 验证：3,000 个序列
- 测试：4,500 个序列

## 指标

| 类别 | Precision | Recall | F1 |
|---|---:|---:|---:|
| Normal | 99.60% | 100.00% | 99.80% |
| Mirai | 99.31% | 95.67% | 97.45% |
| Gafgyt | 95.87% | 99.00% | 97.41% |
| Macro Avg | 98.26% | 98.22% | 98.22% |

总体测试准确率：**98.22%**。

混淆矩阵：

| 实际\\预测 | Normal | Mirai | Gafgyt |
|---|---:|---:|---:|
| Normal | 1500 | 0 | 0 |
| Mirai | 1 | 1435 | 64 |
| Gafgyt | 5 | 10 | 1485 |

## 结论

模型已经从原来的合成数据占位版本，升级为使用九组 N-BaIoT 数据训练的真实模型。主要误差来自 Mirai 与 Gafgyt 的相互混淆。当前结果是抽样 CPU 训练结果，不应伪装成全量 500 万以上样本训练结果；后续应在 GPU 或学校服务器上使用更大的每类样本上限重新训练。

## 1. 项目概述

智慧社区 IoT 僵尸网络入侵检测系统（天津理工大学大创项目）。核心是**设备图 GNN**：从"哪条流是攻击"升级到"哪台设备被感染"，配合分级响应，现场演示完整的攻防闭环。

### 2.2 设备图 GNN 完整链路（本次核心成果）

```
CICIoT2023 数据（含 IP + 标签）
  → 抽样平衡子集（176.6 万行）
  → 建设备图（节点=设备×时间窗口，边=通信+时序，四级风险）
  → 训练 GAT（0.12M 参数）
  → 导出 ONNX（146KB，动态节点数）
```

| 指标 | 结果 |
|------|------|
| 节点数 | 6,421（设备 × 1小时窗口） |
| 特征 | 13 维（IP 无关的流量统计） |
| 模型参数 | 0.12M（极轻量） |
| 僵尸网络检测 | **F1 0.95，漏报 0** |
| 正常设备识别 | F1 0.87 |
| 拒绝服务识别 | F1 0.91 |
| 侦察识别 | F1 0.56（与正常混淆，可接受） |
| ONNX 模型 | 146KB，支持动态节点数 |

**核心安全指标**：僵尸网络从不漏报（326 样本 0 误判为正常）、正常设备几乎不误报（232 样本仅 1 误判）。

### 4.3 接线指南（引脚与固件一一对应）

| 设备 | 执行器/传感器 | 信号脚 | 电源 |
|------|--------------|--------|------|
| 门禁 | SG90 舵机 | GPIO0 | 5V / GND |
| 路灯 | LED（串 220Ω 电阻） | GPIO1 | 负极接 GND |
| 插座 | 继电器 IN | GPIO2 | VCC→5V，GND→GND |
| 传感器 | DHT11 DATA | GPIO3 | 3.3V / GND |
| 音箱 | 蜂鸣器 + | GPIO4 | - 极接 GND |
| 摄像头 | SG90 云台 | GPIO2 | 5V / GND |

> 电平三铁律：① 舵机/继电器从 **5V** 取电，不走 GPIO 的 3.3V；② LED 必须串 220Ω~1kΩ 电阻；③ 继电器买"低电平触发 + 3.3V 信号兼容"，否则 3.3V GPIO 不吸合。

### 4.4 一键通电 + 一键启动

- **一键通电**：6 口 USB 充电器 + 6 条 USB-C 短线，合上排插开关 = 6 台设备同时上电（定稿后可用 5V/5A 电源 + 端子排并联各板 5V/GND，更整洁）。
- **一键启动**：固件已"上电即跑"（自动连热点 → 连 MQTT → 周期遥测），无需按键；唯一一次性工作是烧录（每台一次）。
- **树莓派一键启动**：写 `start.sh` 一条命令拉起 `hostapd + dnsmasq + mosquitto + 后端 app.py`；开机自启可加进 `/etc/rc.local` 或 systemd。
- **一键触发攻击**：`mosquitto_pub -h 192.168.4.1 -t "community/door-01/control" -m "attack"`（`block` 为隔离）。

# 07 - 设备拓扑方案（硬件 + 模拟智慧社区拓扑）

> 状态：设计稿
> 更新日期：2026-08-27
> 关联文档：[06-demo-design.md](06-demo-design.md)

## 1. 概述

本文档定义现场演示的**完整设备拓扑方案**：硬件设备需求（具体型号）、模拟智慧社区的网络拓扑、设备间通信关系、以及设备图 GNN 视角下的图结构。

**核心设计原则**：一个内网 IP = 一台设备；树莓派开热点当网关；设备间既有"星形"遥测通信、又有"设备到设备"的直接通信，使设备图丰富、GNN 有意义。

## 6. 通信流设计（设备图的"边"）

设备之间的通信关系就是 GNN 的边。

### 6.1 星形遥测（设备 → 网关，经 MQTT Broker）

所有设备周期性向树莓派的 MQTT Broker 发布状态（"正常流量"主体）：

| 设备 | MQTT Topic | 频率 |
|------|-----------|------|
| 摄像头 | `community/camera/status` | 5s 心跳 |
| 门禁 | `community/door/state` | 事件触发 |
| 路灯 | `community/light/level` | 10s |
| 插座 | `community/plug/power` | 10s |
| 传感器 | `community/sensor/temp` | 5s |
| 音箱 | `community/speaker/state` | 事件触发 |

### 6.2 设备间直接通信（设备 → 设备，创建网格边）

设计"智能联动"，让设备之间**直接**通信（用直接 HTTP/UDP，形成真实 IP 流）：

| 联动 | 触发 | 动作 | 边 |
|------|------|------|-----|
| 传感器 → 音箱 | 温度 > 30℃ | 音箱播报"高温提醒" | `.14 → .15` |
| 门禁 → 摄像头 | 门被打开 | 摄像头启动录像 | `.11 → .10` |
| 路灯 → 门禁 | 天黑 | 门禁进入夜间模式 | `.12 → .11` |

### 6.3 攻击流量（被感染设备 → 目标）

攻击脚本跑在**被感染的设备**上（无需独立攻击者）：

| 攻击 | 目标 | 特征 |
|------|------|------|
| UDP 洪水 (udpplain) | 摄像头 `.10` | 高频 UDP 包 |
| GRE 洪水 (greip) | 门禁 `.11` | GRE 封装 UDP |
| 端口扫描 (recon) | 全网段 | SYN 扫描 |

## 7. 设备图结构（GNN 视角）

训练好的 GNN 看到的现场图就是这个结构：

```
节点（7 个，不含攻击者）:
  N0 = 192.168.4.1   (网关/Pi)
  N1 = 192.168.4.10  (摄像头)
  N2 = 192.168.4.11  (门禁)
  N3 = 192.168.4.12  (路灯)
  N4 = 192.168.4.13  (插座)
  N5 = 192.168.4.14  (传感器)
  N6 = 192.168.4.15  (音箱)

边（通信关系）:
  星形遥测:  N1→N0, N2→N0, N3→N0, N4→N0, N5→N0, N6→N0
  设备联动:  N5→N6 (传感器→音箱), N2→N1 (门禁→摄像头), N3→N2 (路灯→门禁)
  攻击:     被感染设备→目标 (如 N2→N1, N2→N3)

节点特征（IP 无关的流量统计）:
  总流量数、总包数、总字节数、唯一端口数、协议分布、平均包长、
  通信对数量、流量持续时间 等
```

**关键**：节点特征只用流量统计（IP 无关），IP 只用来定义节点和边。这样现场换 IP（`192.168.4.x`）和数据集（`192.168.137.x`）能无缝衔接。

## 8. 设备针对性反应（被入侵后的物理反馈）

每种设备被入侵后有"专属后果"，用设备自己的执行器实现：

| 设备 | 被入侵后的针对性反应 | 危害叙事 |
|------|---------------------|---------|
| 📷 智能摄像头 | 云台乱转 + 屏幕显示"画面被劫持" | 隐私泄露 |
| 🚪 智能门禁 | 舵机"开门"（锁被打开） | 物理安全失守 |
| 💡 智能路灯 | 灯光疯狂闪烁/熄灭 | 社区陷入黑暗 |
| 🔌 智能插座 | 继电器反复通断（电器乱跳） | 设备损坏/火灾隐患 |
| 🌡️ 温湿度传感器 | 上报假数据（温度飙到 99℃） | 数据被篡改 |
| 🔊 智能音箱 | 发出奇怪声音 | 骚扰/恐慌 |

## 9. 关键连接技术

| 连接 | 技术 | 说明 |
|------|------|------|
| ESP32 → Pi 热点 | WiFi (hostapd) | Pi 开热点，设备连接 |
| 设备身份 | 静态 DHCP (dnsmasq) | MAC 绑定固定 IP |
| 遥测通信 | MQTT (mosquitto) | Broker 跑在 Pi 上 |
| 设备联动 | HTTP/UDP 直连 | 设备间直接 IP 流 |
| 抓包 | scapy/tcpdump | Pi 网关抓全网流量 |
| 隔离 | iptables / MQTT 指令 | 屏蔽 IP 或触发断电 |
